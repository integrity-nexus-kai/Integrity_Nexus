# Post-Publication Action Register

## Purpose

This public register records corrections, replacements, withdrawals, and retractions without storing confidential allegations or private case material.

## Allowed Action Types

```text
CORRECTION
REPLACEMENT
WITHDRAWAL
RETRACTION
NO ACTION AFTER REVIEW
```

## Required Record

```text
Action ID:
Affected artifact and version:
Action type:
Public reason:
Decision authority:
Decision date:
Replacement or corrected version:
Evidence location:
Private case reference, if any: RESTRICTED / NOT PUBLIC
```

## Current Entries

No post-publication action has been registered under this standard.

Absence of an entry is not evidence that no error or concern exists. Confidential case material must not be committed to this public repository.
